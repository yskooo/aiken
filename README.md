# Aiken

Expo + TypeScript scaffold for "Aiken: Custom AI Agent – Digital Twin".

See AIKEN_one-shot-build-prompt.md for full spec (uploaded by the project owner).

Getting started

1. Install dependencies: `yarn` or `npm install`
2. Run the Expo app: `yarn start` or `npm run start`
3. Run TypeScript check: `npm run typecheck`
